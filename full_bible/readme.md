# 📖 전체 66권 자유 성경 통독 앱 (3대 역본 & 대조 비교)

본 폴더는 **구약 39권 + 신약 27권 (총 1,189장)** 성경 66권 전체를 자유롭게 읽고 읽은 장을 기록하는 **전체 성경 통독 앱** 전용 폴더입니다.

## 🌟 주요 기능
1. **3대 역본 선택**: 개역개정, 새번역, 개역한글 자유 전환
2. **역본 대조 비교**: 한 구절 안에서 3대 역본 동시 비교 (`🔍 역본 대조 비교`)
3. **통독 기능**: 🔊 TTS 음성 읽기, 🖍️ 형광펜, 🔖 북마크, 📝 묵상 노트
4. **통독표 매트릭스**: 66권 1,189장 진도율 대시보드 & 체크 그리드
5. **백업/복원**: JSON 파일 데이터 백업 및 복원

## 🚀 GitHub Pages 배포 방법
1. GitHub.com에 새 레포지토리(`full-bible-app`)를 만듭니다 (Public 선택).
2. 이 폴더(`01_전체66권_자유성경통독앱`) 내부의 모든 파일(`index.html`, `bible_db_66.js` 등)을 그대로 업로드합니다.
3. 저장소의 **Settings** -> **Pages**에서 Branch를 **`main`**으로 설정하면 무료 웹 주소가 생성됩니다!
